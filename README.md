# subtitle
用於存放各影片站中影片的對應自製字幕\
包括烤肉、歌詞翻譯等\
由於個人日語能力與時間精力所限，翻譯均採用GPT的長thinking加上一定優化的prompt，姑且還是會看過一遍看有沒有問題。不過現在的thinking翻譯都很強了

分為兩類 完成與未完成
## 完成
比如
```text
├── LYgoPrD_ads.ja+zh-TW.ass                      # 字幕文件，前面那一串是yt的影片id，ja+zh-TW是語言說明
├── font.md                                       # 字幕中用到的字體，為避免版權問題會僅使用開源字體
├── info.json                                     # 來自yt-dlp/yt-dlp的--write-info-json
└── 群青 Love theory (special ver.).ja+zh-TW.txt  # 未對軸的文本
```
完成的話 字幕與文本都有翻譯 因此可隨意選擇

## 未完成
比如
```text
├── jR-hcYro-Kg.ja.ass                             
├── info.json                                      
└──【雑談】深夜だよ【ぶいすぽ⧸如月れん】.ja+zh-TW.md  
```
未完成的話，字幕文件就只有asr結果，純日文還包含大量識別錯誤\
.md則是經過修正與翻譯的未對軸文本，因此建議直接看md\
github原生支持目錄，點擊右上角outline就能看到\
md看到感興趣的地方的話，可以在字幕檢索對應日文直接定位到對應影片位置對着看

一般這類都是長時間的雜談直播，一是單人雜談的話asr識別效果好，其次雜談沒畫面，看文本迅速能了解內容，最後幾小時對軸還是太費時間了，而且意義不大
